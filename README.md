
# Filtrando Pessoas com Java Streams

## Sobre o projeto
Projeto desenvolvido em Java para praticar a manipulação de listas utilizando Streams.

## Funcionalidades
- Filtrar pessoas maiores de 18 anos.
- Extrair os nomes com `map()`.
- Ordenar os nomes com `sorted()`.
- Exibir os resultados com `forEach()`.

## Tecnologias
- Java
- Stream API
- Lambda Expressions
- Method Reference

## Objetivo
Praticar filtros, transformação de dados e ordenação de coleções em Java.
